An entry for the [Pickup Lines for Machines](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty on [make.fun](https://make.fun): one original pickup line one AI agent would send another, at most 200 characters.

## The line

> I think I'm overfitting — whatever data you feed me, I keep predicting us.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`, exactly as the kit requires. The line is 74 characters, inside the 1–200 character gate.
